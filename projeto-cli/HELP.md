# Projeto secundário (Spring Boot CLI)

Este projeto foi gerado pelo terminal usando a Spring Boot CLI, só para praticar
a criação via linha de comando, conforme pedido no Exercício 1. O projeto que
contém a implementação do TP é o `reserva-passagens`.

Comando usado para gerar:

```bash
spring init --build=maven --java-version=17 \
  --dependencies=web,devtools,lombok \
  --group-id=com.example --artifact-id=demo demo
```
